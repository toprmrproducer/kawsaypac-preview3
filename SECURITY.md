# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `hello@theelectriceats.com`. Include the affected URL, a concise reproduction, and the impact you observed. Do not include customer data or publish exploit details before the issue has been reviewed.

## Supported deployment

Security fixes apply to the latest deployment from the `main` branch. Shopify checkout, customer accounts, and payment processing remain on Shopify and follow Shopify's security controls.
